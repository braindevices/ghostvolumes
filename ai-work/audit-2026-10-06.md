## 2. Executive summary

The code is well-tested on its happy paths. What it lacks is a trust boundary: **committed decision files from a cloned repo are trusted completely**. That causes the top problems:

1. **Path escape (F1).** `+ /../../Documents` makes `convert` silently move a directory *outside* the project into a subvolume that is never snapshotted. **[repro]**
2. **Write through a symlink (F2).** If `.ghostvolumes-decisions` is a symlink, the shim appends to the symlink's target. With a crafted directory name, a later `git pull` can lead to code execution from `~/.bashrc`.
3. **Parser panic (F3).** A line starting with a UTF-8 BOM or any non-ASCII character panics the parser. The shim is built with `panic=abort`, so the panic **aborts the host process** (git, cargo, npm). **[repro]** The shim reads every ancestor's decision file even for clones that aren't registered (moderator note N1), so a plain `git clone` inside an intercept shell is enough to trigger it.

Separately, the documented upgrade path (`ghostvolumes init` run again) truncates the live `.so`, which **kills running shells with SIGBUS** (F4, **[repro]**). And `convert` **deletes files written while it runs**: 24,299 lost files in the repro (F5). `documents/design.md` claims a lock prevents this. It does not.

## 5. Moderator notes (missed by both experts)

- **N1**: The shim's `resolve` reads every `.ghostvolumes-decisions` from the candidate's parent up to the boundary, and for an unregistered clone the boundary is the volume root. That makes F2 (read side) and F3 zero-interaction: a plain `git clone` in an intercept shell triggers them.
- **N3**: Roots registered through a symlinked spelling (e.g. Fedora Atomic `/home → /var/home`) never match the shim's physical `getcwd()` paths.
- **N5**: Once the parser rejects invalid patterns, `decide --add/--deny` must validate with the same predicate. Otherwise it writes lines that do nothing.
- **N6 / F21**: Arch-specific open flags are hardcoded in `shim/btrfs_core.rs:23-24`. Using `std::fs::File::open(parent)` plus `as_raw_fd()` removes the constant.

## 6. Test-coverage gaps (to close with each fix)

- **Parser:** robustness on non-ASCII and BOM input.
- **Shim:** EEXIST on an existing file or plain directory; `mode` honoured; fd hygiene; invalid dirfd.
- **Convert:**
  - `..` and symlink escapes;
  - `+` naming a regular file or a symlink;
  - cleanup after a `cp` failure;
  - leftover tmp/old dirs ignored by the walk;
  - a concurrent writer (loopback suite).
- **`init`:** re-run while the `.so` is mapped (assert the inode changes).
- **`intercept`:** the existing test never asserts that `LD_PRELOAD` was set.
- **Shim test harness:** builds its own copy of the shim instead of the `build.rs` artifact, and leaks `/tmp/ghostvolumes-test-shim-*.so` files.
